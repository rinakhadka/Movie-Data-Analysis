#  Movie Data Analysis

##  Project Overview

This project explores a movie dataset using **Python and Pandas** to understand patterns in movie performance, revenue, ratings, budgets, production companies, and release years.

The analysis focuses on **data inspection, data quality checks, exploratory data analysis (EDA), correlation analysis, and visualization**.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

##  Analysis Performed

The notebook includes:

* Loading and inspecting the movie dataset
* Checking data types and missing values
* Identifying duplicate records
* Exploring numerical variables
* Finding the highest-grossing movies
* Analyzing the relationship between **budget and gross revenue**
* Analyzing the relationship between **movie score and gross revenue**
* Performing correlation analysis
* Examining gross revenue by production company
* Analyzing company performance across different years
* Extracting release years from release dates
* Exploring categorical variables
* Creating visualizations to identify patterns and relationships

##  Key Questions

Some of the questions explored in this project include:

* Which movies generated the highest gross revenue?
* Is there a relationship between movie budget and gross revenue?
* Does movie score have a relationship with gross revenue?
* Which production companies generated the most revenue?
* How does company performance vary across years?
* What relationships exist between the numerical variables?
